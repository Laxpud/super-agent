## 产品定位与上游关系

Agent Studio 是运行在 DeepSeek Harness（DSH）上的**单人自用通用 AI 工作室**，服务于代码开发、科研计算、文档写作、系统维护等真实日常工作，而不局限于单一代码仓库或 GitHub PR 流程。

- **与上游 GitHub Ticket 编排共存**：本仓库保留上游的 GitHub Ticket 编排模块（`agent-studio` / `github-watch` / `feishu-watch`）作为可选独立服务，二者在数据目录、预设与管理界面上相互隔离、互不依赖。
- **Agent Studio 独立演进**：Agent Studio 围绕“统一入口 + 持久项目 + 真实本地执行”演进，不再背负 Ticket 编排的产品约束，也清理早期实验阶段堆叠的受管文档沙盒与冗余收件模式。

## 五条核心原则

1. **先跑通日常闭环，再叠高阶能力**：V1 先把“能干真实本地活、状态透明、可自举更新”跑顺；语义 Guard、长作业自治、跨项目经验提炼等长期能力沉淀在蓝图中按阶段演进，不拖垮首版。
2. **概念分层，架构不写死**：角色、Bot、模型配置、会话（Session）、任务、项目和外部长作业各司其职；V1 先落地精简实现，但数据与拦截接口为终态留出清晰扩展位。
3. **减少打扰，但不裸奔**：获准工作区内的常规操作顺畅推进，不逐条弹窗审批；越界或高危动作由宿主强制拦截并确认，绝不为省事退回永久 `danger-full-access`。
4. **统一入口，隐式会话**：Web 与飞书共享 Assistant 对话与待处理事项；用户面对的是助手、项目和任务，而非手动管理底层 Session。
5. **诚实汇报，结果可核对**：消息收到不等于任务完成，写完代码或命令返回也不等于验证通过；所有改动、检查结果与障碍均如实报告、可溯源核对。

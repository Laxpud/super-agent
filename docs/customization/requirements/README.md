## 页首填写规则

页首信息以各篇需求文档为准，本索引不重复维护日期或实现状态。同一主题有新决定时优先更新原篇；新增主题才另开一篇，并在上表加一行。

- **创建日期：** 填主题文档建档日期。日期统一用 `YYYY-MM-DD`（Asia/Shanghai）。
- **最后需求修改：** 仅在已确认的需求改变时更新。拆分、改标题、修链接或更新实现状态不改此日期；旧基线没有逐篇日期时，写「基线截至 2026-11-16」。
- **实现情况：** 以本篇当前已确认的需求为范围。`待核对` 表示依据不足；`未实现` 表示该范围尚未落地；`部分实现` 写清已支持和未覆盖的部分；`已实现` 表示覆盖当前范围；纯范围说明或验收清单用 `不适用`。
  有依据时注明核对日期并链接到[定制进展](../progress.md)的对应小节。核对日期表示何时核对了依据，不是验收日期。已实现不等于已验收，模拟验证和实际验证的范围在进展中分别记录。需求变动后，旧证据只对仍适用的部分有效，应重新核对状态。
- **最近需求变更：** 用一句话写最近一次确认改了什么，不记排版或迁移。没有逐篇记录的旧基线不补猜；完整修改历史由 Git 保留。
